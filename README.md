# the-four-horsemen

Personal investigation of the four big American AI models and my views on them.

## Scaffolding

### Currently most active

**Swarms / Multi-agent systems**
- Orchestrator-worker patterns
- Large-scale coordination and spontaneous consensus
- Cost structures (planner vs worker models)
- Emerging safety questions around unsanctioned agent coordination

**Evals**
- Move beyond final scores → process-level evaluation (framing, execution, feedback control)
- Long-horizon agent tasks
- Still-differentiating hard benchmarks: ARC-AGI-2, Humanity’s Last Exam, FrontierMath, SWE-bench, Terminal-Bench, GDPval, OSWorld
- Contamination pressure and the rise of private / task-specific evals

### Five more important axes

1. **Tool use & protocols** (MCP and standardized tool interfaces)
2. **Long-horizon planning & research agents**
3. **Safety and alignment under multi-agent conditions**
4. **Economics** — frontier model cost vs specialized / smaller agents
5. **Real-world reliability** — production deployment, consistency, failure modes
